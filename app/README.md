# KR1688 App Skeleton

This is the local fallback foundation for KR1688.

## Why this exists

The official Payload website starter bootstrap was attempted on 2026-08-03 but did not complete reliably through the CLI interaction flow, so this local skeleton was created to keep KR1688 moving forward without mixing into PV.

## Intent

- Product: Saudi-first, Arabic-native story platform
- Direction: Payload + Next.js foundation
- Current role: AI-readable and executor-ready app skeleton

## First build boundaries

- No deployment
- No secrets
- No payments
- No search/recommendation
- No author ecosystem

## App structure

- `src/app` — frontend route shell direction
- `src/collections` — future Payload collection boundaries
- `src/globals` — site-wide settings direction
- `src/payload.config.ts` — Payload configuration direction

## Next step

Replace this fallback skeleton with an official Payload website starter import, or map the official starter onto this structure in a later approved task.
